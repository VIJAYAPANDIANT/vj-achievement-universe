Welcome to the **Cosmic Certificate & Achievement Decryption Console**—a highly gamified, interactive, space-themed developer portfolio and certification vault. Built to look and feel like a sci-fi telemetry HUD (Heads-Up Display), this application catalogs and decrypts **170+ verified credentials**, including internships, hackathons, courses, workshops, skill badges, and competitive programming milestones.

Designed with rich, futuristic aesthetics, glassmorphism, smooth neon gradients, micro-animations, optimized canvas particle systems, custom Web Audio API feedback, and 3D hover interactions.

> [!NOTE]  
> **System Alert**: This application utilizes high-fidelity canvas processing, audio ripples, and Framer Motion state transitions. Make sure your browser's audio permissions are active to experience full sound telemetry.

## 🚀 Operational Modules

The console maps distinct operational modules via the top HUD navigation bridge:

| Module | Icon | Functionality Description |
| :--- | :---: | :--- |
| **Universe** | 🌌 | An interactive, draggable 3D orbital galaxy mapping achievements across cosmic trajectories. Drag the core to rotate system vectors. Features an integrated operator profile panel displaying live telemetry and external profile nodes. |

| **Timeline** | ⏳ | A chronological flight track mapping academic and professional development milestones across months and years with dual-track sorting. |
| **Analytics** | 📊 | A real-time diagnostics dashboard rendering interactive data visualizations: **Achievement Growth Curve** (Line), **Category Proportion Matrix** (Donut), and **Skill Compass Index** (Radar). |
| **Command Center** | 👨‍🚀 | The central operations bridge featuring live operator telemetry protocols, 10 featured holographic achievements across balanced responsive rows, interactive technology scanner, and a full-width bottom external command dock. |

## 🛠️ Technological Architecture

This application leverages a modern, high-performance web stack:

- **Core Framework**: [React 19](https://react.dev/) + [TypeScript 6](https://www.typescriptlang.org/) (for robust type safety and component-driven architecture)
- **Build Tool**: [Vite 8](https://vite.dev/) (for lightning-fast Hot Module Replacement and optimized production bundling)
- **Styling & Layout**: [Tailwind CSS v4](https://tailwindcss.com/) (custom glassmorphism, neon glows, and dark-space color tokens)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (powering seamless page routing, modal decryption overlays, and interactive hover states)
- **Data Visualization**: [Recharts](https://recharts.org/) (driving interactive SVG graphs, donut breakdowns, and polar radar coordinates)
- **Icons**: [Lucide React](https://lucide.dev/) (providing clean, vector HUD iconography)
- **Interactive Effects**: Custom HTML5 Canvas (powering 3D galaxy particles and orbital nodes) and Web Audio API (synthesized sound effects)

## 📡 Local Deployment

To run this telemetry HUD console on your local coordinates:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/VIJAYAPANDIANT/vj-achievement-universe.git
   cd vj-achievement-universe
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Boot up the development server**:
   ```bash
   npm run dev
   ```
   Click the provided terminal URL (typically `http://localhost:5173`) to launch the application.

4. **Assemble the production build**:
   ```bash
   npm run build
   ```
   Compiles the production-ready code bundles into the `dist` directory.

5. **Preview the production build**:
   ```bash
   npm run preview
   ```
